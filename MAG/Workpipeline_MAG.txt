MAG (Microsoft Academic Graph, Dec 2021 snapshot) replication of the OpenAlex pipeline.
Paths come from utils.py in this same directory: MAG_DATA_DIRE (the snapshot's mag/ folder:
Papers.txt, PaperReferences.txt, PaperAuthorAffiliations.txt, Affiliations.txt),
MAG_ADVANCED_DIRE (the sibling advanced/ folder: PaperFieldsOfStudy.txt, FieldsOfStudy.txt) and
META_DIRE (= ./data, where every processed file is written). Every script inserts its own
directory on sys.path so utils.py resolves regardless of the working directory.
Snapshot conventions shared by the whole pipeline: only journal papers (DocType == 'Journal') are
kept, references to papers published after the citing paper are dropped, focal papers must satisfy
1945 <= pub_year < max_year (= 2021) and citation windows are capped at max_year - 1 (= 2020).
year_offset == -1 is the NO-CITATION-WINDOW sentinel, the same one OpenAlex uses: there is no
window to leave room for, so every citation up to the data horizon counts and the cap alone
applies (max_year_threshold = max_year - 1 = 2020). Note the horizon differs from OpenAlex's
(2025) because the snapshot does -- getting it wrong claims papers get_efg.py never computed.

Run order (every input below is produced by an earlier script here, except the raw MAG snapshot
read by get_paper_meta.py):
	get_paper_meta.py
	-> get_disruption.py -> arrange_disruption.py
	-> get_efg.py -> get_efg_s2_merge.py (use_disp_f=False)
	-> get_efg_v2_disp_f.py -> get_efg_s2_merge.py (use_disp_f=True)
	-> compute_efg_quantile_by_domain.py   (needs all three of the above)
	-> get_author_academic_age.py
	-> plot_academic_age_peryear_person_top_efg.py / plot_country_avg_age_vs_efg.py
year_offset must be identical everywhere, and reference_threshold / citation_threshold must
match between compute_efg_quantile_by_domain.py and any plotting script reading its output — the
quantile directory name is built from those two values, so a mismatch fails as a missing directory
rather than silently ranking papers against the wrong peer set.
Two more settings are point-to-point in the same way, both on the disruption side:
  year_tag      = '' when year_offset == 5, '_y{year_offset}' otherwise. get_disruption.py tags
                  every per-division file with it and arrange_disruption.py tags disp_full with
                  it, so year_offset = 5 keeps the names already on disk and any other window
                  writes beside them instead of over them. Every consumer rebuilds the same tag
                  from its own year_offset (disp_year_tag), so a mismatch fails as a missing file.
  disp_k_suffix = '' when k_require_after_focal (the default), '_k_no_lower_bound' otherwise --
                  which of get_disruption.py's two K definitions to read. It is a SETTING in every
                  consumer (compute_efg_quantile_by_domain.py, plot_country_avg_age_vs_efg.py),
                  not a hardcoded string: hardcoding it made them look for a file the current
                  get_disruption.py setting never writes.
So every disp_full read in this pipeline is disp_full{year_tag}{disp_k_suffix}.csv.

>>>>>>>>> Mata data process

get_paper_meta.py
	description: Parses the raw MAG tables into the metadata and citation network the rest of the pipeline runs on. Each big table is split into line-aligned byte ranges and processed with a ProcessPoolExecutor (process_count = min(16, cpu_count)). Papers.txt -> pid2title (OriginalTitle, falling back to PaperTitle) and pid2pub_year, keeping DocType == 'Journal' only; FieldsOfStudy.txt + PaperFieldsOfStudy.txt -> pid2field_of_study, keeping only level-0 (FOS_LEVEL_TO_KEEP = 0) field DisplayNames, i.e. the MAG analogue of the OpenAlex level-0 concepts; Affiliations.txt -> affiliation id -> Iso3166Code, then PaperAuthorAffiliations.txt -> pid2author_list (author ids ordered by AuthorSequenceNumber, de-duplicated) and the parallel pid2author_country_list (per author, the sorted de-duplicated list of their affiliation countries on that paper; [] when the affiliation is missing — authors are never dropped for a missing affiliation); PaperReferences.txt -> citing_pid2cited_pids_list / cited_pid2citing_pids_list, keeping an edge only when BOTH endpoints are journal papers and the cited year is not later than the citing year (the temporal filter of the OpenAlex pipeline), then de-duplicating both directions. Each of the four stages is skipped when its output already exists, so the script is resumable.
	input: MAG_DATA_DIRE/{Papers.txt, PaperReferences.txt, PaperAuthorAffiliations.txt, Affiliations.txt}, MAG_ADVANCED_DIRE/{PaperFieldsOfStudy.txt, FieldsOfStudy.txt}
	output (to META_DIRE = data/): pid2title.pkl, pid2pub_year.pkl, pid2field_of_study.pkl, pid2author_list.pkl, pid2author_country_list.pkl, citing_pid2cited_pids_list.pkl, cited_pid2citing_pids_list.pkl

temp.py
	description: Sanity-check / corpus-statistics helper (not part of the pipeline). Counts the unique publications (pids with a year), the papers carrying an author list, the unique authors, and the authors with at least MIN_PUBLICATIONS (3) publications, and prints them.
	input: data/pid2pub_year.pkl, data/pid2author_list.pkl (from get_paper_meta.py)
	output: printed to stdout only

>>>>>>>>>  Compute disruption

get_disruption.py
	description: MAG version of the WoS get_disruption.py: computes the disruption index and the I/J/K citation counts for every journal paper. For a focal paper P, each paper citing P within year_offset_main years is classified as developmental (J, it also cites at least one of P's references) or disruptive (I, it cites none of them); K is the set of papers citing P's references, minus J; the index is (I - J) / (I + J + K). Papers are split into division_count (20) divisions, each written with a finished-flag so runs are resumable and splittable across machines (start_division / end_division bound the range processed); process_count = 4 workers per division. k_require_after_focal selects the K window: True (the default used here) counts only references' citers published on/after P, False drops that lower bound and tags every output with '_k_no_lower_bound' (k_suffix) so the two variants never collide. year_offset_main == -1 is the NO-WINDOW sentinel, handled as in OpenAlex: NO_WINDOW makes max_year_threshold NO_WINDOW_MAX_YEAR = max_year - 1 (2020) instead of min(focal_pub_year + year_offset_main, max_year - 1), so every citation up to MAG's horizon counts and nothing else changes. The focal-paper guard (1945 <= pub_year < max_year) is untouched. Every file this script writes carries year_tag ('' at the default 5, '_y{year_offset_main}' otherwise), so two citation windows never overwrite each other and the year_offset = 5 files already on disk keep their names. There is no '_with_review' variant — the MAG network is journal-only.
	input: data/{pid2pub_year.pkl, pid2title.pkl, citing_pid2cited_pids_list.pkl, cited_pid2citing_pids_list.pkl} (from get_paper_meta.py)
	output (to META_DIRE/disruption_division/): disp_paper{year_tag}[_k_no_lower_bound]_d_{division_index}_max_{division_count}.csv (pid, title, pub_year, up_refer_count, and the J/I/K/citation/disp columns named for the window: J_count_y{off}, I_count_y{off}, K_count_y{off}, citation_count_y{off}, disp_y{off}, disp_no_J_numer_y{off}), plus disp_finished{year_tag}[_k_no_lower_bound]_d_{division_index}_max_{division_count}.pkl markers and pid2up_reference_id_list{year_tag}_d_{division_index}_max_{division_count}.pkl

arrange_disruption.py
	description: MAG version of the WoS arrange_disruption.py: concatenates the per-division disruption CSVs into a single table, asserting that pids are unique. k_require_after_focal must match get_disruption.py (it selects the k_suffix on both the inputs and the output), and so must year_offset_main, which selects year_tag the same way on both sides -- a per-division file is asserted to exist, so a mismatch fails naming the file and the year_offset_main to re-run get_disruption.py with, rather than silently merging the wrong window. An existing output file is not overwritten.
	input: META_DIRE/disruption_division/disp_paper{year_tag}[_k_no_lower_bound]_d_{division_index}_max_{division_count}.csv (from get_disruption.py, same year_offset_main / k_require_after_focal)
	output (to META_DIRE/disruption/): disp_full{year_tag}[_k_no_lower_bound].csv (year_tag = '' at year_offset_main 5, '_y{year_offset_main}' otherwise -- this is the file every downstream script rebuilds the name of from its own year_offset)

>>>>>>>>>  Compute F, E, G index

get_efg.py
	description: MAG version of get_efg.py: computes the E/F/G index on the MAG citation network. For each focal paper (1945 <= pub_year < max_year = 2021) it takes the citing papers published within year_offset (5) years — capped at max_year - 1, or all citations up to that cap when year_offset == -1 — and for every citing paper compares up_count (how many of the focal paper's references it shares) with down_count (how many of the focal paper's other citing papers it co-cites): up_count == down_count == 0 counts toward G, up_count > down_count toward E, down_count > up_count toward F, and a non-zero tie splits 0.5/0.5 between E and F. Also emits the citation-normalised shares e_y5/f_y5/g_y5 (0 when there are no citations). Work is split into division_count (20) divisions, each with a finished-flag for resumability, and process_count (3) worker processes per division. network_mode ('normal' -> network_suffix '') is encoded in both the input network filenames and the outputs so future network variants never overwrite each other.
	input: data/{pid2pub_year.pkl, citing_pid2cited_pids_list.pkl, cited_pid2citing_pids_list.pkl} (from get_paper_meta.py)
	output (to META_DIRE/efg_computation/): gen_V3_y{year_offset}_d_{division_index}_max_{division_count}.csv (pid, pub_year, up_refer_count, citation_count_y5, e/f/g_count_y5, e/f/g_y5) + gen_V3_y{year_offset}_finished_d_{division_index}_max_{division_count}.pkl markers

get_efg_v2_disp_f.py
	description: Same computation as get_efg.py plus the three "disruptive foundation" (disp_f) variants, counted in the same single pass: a citing paper counts toward disp_f when it shares NONE of the focal paper's references (up_count == 0) yet co-cites more than T of the focal paper's other citing papers (down_count > T), for T in DISP_F_DOWN_THRESHOLDS = [0, 1, 2]. The T = 0 variant keeps the legacy column names (disruption_f_count_y5 / disruption_f_y5) so existing downstream scripts keep working; T > 0 gets a _down_gt{T} tag. Same 20 divisions / 3 processes / finished-flags / network_suffix scheme as get_efg.py, with its own file prefix so the two runs never collide -- year_offset == -1 included: as in get_efg.py it takes every citation up to the data horizon (max_year - 1) instead of the year_offset window, so the two stay on the same population.
	input: data/{pid2pub_year.pkl, citing_pid2cited_pids_list.pkl, cited_pid2citing_pids_list.pkl} (from get_paper_meta.py)
	output (to META_DIRE/efg_computation/): gen_V3_disp_f_y{year_offset}_d_{division_index}_max_{division_count}.csv (the gen_V3 columns + disruption_f_count_y5 / disruption_f_down_gt1_count_y5 / disruption_f_down_gt2_count_y5 and their citation-normalised shares) + gen_V3_disp_f_y{year_offset}_finished_d_{division_index}_max_{division_count}.pkl markers

get_efg_s2_merge.py
	description: Concatenates the per-division E/F/G CSVs into one table, asserting that every division's finished-flag and CSV exist. No filtering is applied here — downstream scripts apply their own pub_year / reference / citation thresholds. use_disp_f selects which run to merge (False -> get_efg.py's gen_V3_*, True -> get_efg_v2_disp_f.py's gen_V3_disp_f_*), and year_offset / division_count / network_mode must match the script that produced the divisions; the choice is encoded in the output filename so the two runs never collide. Run it once with each use_disp_f value — the downstream scripts read both tables.
	input: META_DIRE/efg_computation/{gen_V3|gen_V3_disp_f}_y{year_offset}_d_{division_index}_max_{division_count}.csv (+ the matching _finished_*.pkl) from get_efg.py / get_efg_v2_disp_f.py
	output (to META_DIRE/efg_computation/): gen_V3_y{year_offset}.csv or gen_V3_disp_f_y{year_offset}.csv

>>>>>>>>>  Compute F, E, G quantiles by domain

compute_efg_quantile_by_domain.py
	description: MAG counterpart of openalex/compute_efgd_quantile.py: gives every paper its percentile rank (quantile in (0, 1]) among its peers, for the same metric set, so the two pipelines are comparable. Papers enter a peer group only if up_refer_count >= reference_threshold and citation_count_y5 >= citation_threshold. Because pid2field_of_study maps a paper to a LIST of level-0 domains, the table is exploded to one row per (pid, domain) and the paper is ranked once per domain it belongs to. Two rankings are written for every metric: {col}_quantile, computed WITHIN the paper's (domain, pub_year) peer group, and {col}_quantile_global, computed over all threshold-passing papers pooled with no grouping. COMBINE_DOMAINS additionally defines merged domains ({merged_name: [domain, ...]}, here 'Social science' and 'Geoscience'); a paper in any listed domain is pooled once into the merged domain, ranked within that merged domain-year, and saved as its own CSV alongside the individual ones (so a paper can appear in both files under two different rankings — downstream scripts must not average both). Metrics quantiled: E/F/G (e/f/g_y5), the disruption index disp_y5, R = i/(i+j) (ij_ratio_y5), i/(i+j+k) (i_over_ijk_y5), f/(i+j+k) (f_over_ijk_y5), disp_f0/(i+j+k) (dispf_over_ijk_y5) and the three disp_f shares — every ratio derived from the raw COUNTS, never from the citation-normalised shares. disp_full and gen_V3_disp_f are LEFT-joined, so a paper missing from either keeps its E/F/G quantiles and gets NaN only for the metrics it lacks. use_disp_f (True) adds the disp_f columns; year_offset / thresholds must match the upstream scripts. The disruption file is addressed as disp_full{disp_year_tag}{disp_k_suffix}.csv: disp_year_tag is rebuilt from THIS script's year_offset ('' at 5, '_y{year_offset}' otherwise) so it follows get_disruption.py's window, and disp_k_suffix comes from k_require_after_focal, which is a SETTING here and must match the get_disruption.py run -- it used to be hardcoded to '_k_no_lower_bound', which at the current default (True, no suffix) pointed at a file that is never written. year_offset == -1 needs nothing special in this script: it applies no pub_year cut of its own, so it simply ranks whatever population the no-window gen_V3 / disp_full hold, and the y{year_offset} in the output directory and filenames keeps that run separate.
	input: META_DIRE/efg_computation/gen_V3_y{year_offset}.csv (from get_efg_s2_merge.py), META_DIRE/disruption/disp_full{disp_year_tag}{disp_k_suffix}.csv (from arrange_disruption.py, same year_offset / k_require_after_focal), META_DIRE/efg_computation/gen_V3_disp_f_y{year_offset}.csv (from get_efg_s2_merge.py with use_disp_f=True; only when use_disp_f), data/pid2field_of_study.pkl (from get_paper_meta.py)
	output (to META_DIRE/efg_computation/efg_within_year_domain_quantile_y{year_offset}_rt_{reference_threshold}_ct_{citation_threshold}/): one CSV per level-0 domain and per merged domain, {domain}_y{year_offset}_rt_{reference_threshold}_ct_{citation_threshold}.csv (pid, pub_year, domain, group_size, up_refer_count, citation_count_y5, the raw metric values, their within-(domain, year) {col}_quantile columns, and their {col}_quantile_global columns)

>>>>>>>>> Academic age analysis

get_author_academic_age.py
	description: Turns the per-paper author lists into per-author career records. Inverts pid2author_list into author -> papers (papers with a known publication year only), de-duplicates each author's papers, keeps authors with at least MIN_PAPERS (3) papers, and defines each paper's academic age for that author as pub_year(paper) - the author's earliest pub_year.
	input: data/pid2author_list.pkl, data/pid2pub_year.pkl (from get_paper_meta.py)
	output (to META_DIRE = data/): author2paper_list.pkl, author2first_pub_year.pkl, author_paper_academic_age.pkl

plot_academic_age_peryear_person_top_efg.py
	description: Academic age (every single year 0..MAX_AGE is its own bin) vs. the probability of publishing a top-10% F/E/G/Disruption paper, averaged OVER PEOPLE. An author is kept only if they have >= MIN_PAPERS (3) papers in total, a career age (max academic age reached) >= CAREER_MIN_AGE (40) and a first publication year in [FIRST_PUB_YEAR_MIN, FIRST_PUB_YEAR_MAX] = [1960, 1970]; the top-10% ratio itself is computed only over their threshold-passing (quantiled) papers with pub_year < MAX_YEAR = 2021 - year_offset. For each line (a domain, or the pooled "All fields" line when INCLUDE_ALL) and each academic-age year, every author who published at least one paper in that line and year contributes their ratio of top-10% papers (quantile >= TOP_QUANTILE = 0.90); the plotted point is the mean of those per-author ratios and the 95% CI is bootstrapped OVER PEOPLE (N_BOOT resamples of the contributing authors). Years in which an author published nothing are simply skipped, so the contributing-author count varies by year, and cells with fewer than MIN_AUTHORS (30) authors are dropped. QUANTILE_MODE selects which ranking defines "top 10%" ('domain' -> {col}_quantile, 'global' -> {col}_quantile_global). Disruption is treated exactly like E/F/G and drawn as an inset on the Generalization panel. DOMAINS_TO_PLOT is a plot-time filter only — the cache always holds every domain, so changing it redraws without recomputing (force_recompute overrides the cache). reference_threshold / citation_threshold / year_offset must match the quantile directory being read.
	input: data/author_paper_academic_age.pkl, data/author2first_pub_year.pkl (from get_author_academic_age.py), META_DIRE/efg_computation/efg_within_year_domain_quantile_y{year_offset}_rt_{reference_threshold}_ct_{citation_threshold}/*.csv (from compute_efg_quantile_by_domain.py run with THIS script's reference_threshold / citation_threshold / year_offset — the directory name is built from them, so a mismatch is a missing-directory error. NOTE this script is currently set to reference_threshold=1, citation_threshold=1 while compute_efg_quantile_by_domain.py is set to citation_threshold=5, so that script must be re-run with citation_threshold=1 to produce this input)
	output (to ./figures/academic_age_peryear_person_top_efg/): academic_age_peryear_person_top{top_pct}_efg_{agg_suffix}{filter_suffix}_pa{PLOT_MAX_AGE}_ma{MIN_AUTHORS}_ci{CI_LEVEL}_{domain_tag}.svg/.png, plus the caches academic_age_peryear_person_bootci{CI_LEVEL}_{agg_suffix}{filter_suffix}_nboot{N_BOOT}_seed{BOOT_SEED}.csv and academic_age_peryear_person_nscientists_{agg_suffix}{filter_suffix}.csv

>>>>>>>>> Country analysis

plot_country_avg_age_vs_efg.py (Extended Data Fig. 10b)
	description: Country-level scatter of average academic age vs. average index. Every (paper, author) instance of a valid author (the >= MIN_PAPERS authors kept by get_author_academic_age.py) is attributed to that author's AFFILIATION country ON THAT PAPER, so the country follows the author's academic age; instances are restricted to gen_V3 papers passing the reference/citation thresholds with pub_year < SELECT_MAX_YEAR. MAX_YEAR is DERIVED: 2021 - year_offset normally (the paper's own window must fit before the 2020 horizon), but 2021 at year_offset == -1, where there is no window to leave room for and the condition degenerates to 'the paper is within the horizon' -- applying the formula literally there would give 2022, past MAG's data. SELECT_MAX_YEAR narrows the analysed period further (only pub_year < SELECT_MAX_YEAR, the same strict-less-than); leave it equal to MAX_YEAR for no narrowing. It must be <= MAX_YEAR (asserted), because MAX_YEAR is the window the citation counts were built for and later papers would carry incomplete ones. It is applied at every one of the script's pub_year cuts -- the quantile load, the raw F/E/G load, the disruption load, the disp_f load, the (i+j+k) load and the scatter subset -- and on the USE_QUANTILE path the quantiles are NOT recomputed, so a further assert requires QUANTILE_GROUP = 'year_domain' (its groups are (domain, pub_year), so every surviving paper is still ranked against its own same-year peers); a 'global' rank was computed against the years now dropped. Per country it averages the academic age (x) and the index (y) over all such instances, drops countries with fewer than MIN_INSTANCES (500) instances, annotates each point with its country code (ANNOTATE) and fits a regression per panel (cached to CSV). The main figure is 1x3 (Foundation / Extension / Generalization) with average disruption drawn as an inset on the Generalization panel; USE_DISP_F adds a second row of three panels, one per disp_f variant (down>0 / down>1 / down>2), and tags its caches/figures with '_dispf3'. PLOT_IJK draws a SECOND, independent 1x4 figure of the (i+j+k)-denominator ratios — F/(C+K), Disp(F)/(C+K), I/(C+K), (I-J)/(C+K) where C = I+J — computed from the raw COUNTS rather than the shares, with its own panels, fits and caches. USE_QUANTILE picks what is averaged: False averages the raw per-paper indices (reading gen_V3 / disp_full / gen_V3_disp_f and deriving the (i+j+k) ratios from the counts), True averages each paper's quantile from compute_efg_quantile_by_domain.py (QUANTILE_GROUP 'year_domain' -> {col}_quantile, 'global' -> {col}_quantile_global; a paper in several domains takes the mean over its domains, and the merged COMBINE_DOMAINS files are dropped by checking the domain names against pid2field_of_study so no paper is counted twice under two incompatible rankings). Every cache and figure name carries value_tag = '_quantile_{QUANTILE_GROUP}' when USE_QUANTILE, so the raw and quantile runs coexist, and every one of them flows from agg_suffix = y{year_offset}_rt_{reference_threshold}_ct_{citation_threshold}_maxyear{SELECT_MAX_YEAR} -- note maxyear carries SELECT_MAX_YEAR, the period actually plotted, not MAX_YEAR, the window the inputs were built for, so a narrowed run neither reuses nor overwrites the full one. The disruption and (i+j+k) paths read disp_full{disp_year_tag}{disp_k_suffix}.csv, both tags rebuilt from this script's own year_offset / k_require_after_focal setting. force_recompute bypasses the caches. One combination is singled out by the is_ed_fig flag — USE_DISP_F=False, USE_QUANTILE=False, year_offset=5, reference_threshold=1, citation_threshold=5 and SELECT_MAX_YEAR == MAX_YEAR — because that raw, disp_f-off, un-narrowed run IS the Extended Data deliverable (a narrowed period is a different population, and without that last clause it would have written its caches and figure straight over the panel's name, which every other name avoids via agg_suffix): its 1x3 figure and the three caches feeding it (the per-country E/F/G aggregate, the disruption-inset aggregate and the regression table) are named after the panel instead of carrying the parameters, so the deliverable's data is not split across two naming schemes. MIN_INSTANCES is deliberately left out of that gate, so it no longer appears in those filenames and a different value overwrites the same files rather than writing a separate one. The separate 1x4 (i+j+k) figure is not part of the deliverable and is unaffected. Because of the rename, a first run at the deliverable setting will not find the old country_avg_age_efg_agg_* / country_avg_disp_agg_* caches and recomputes them (the disruption one re-reads disp_full, the slow part) unless the existing files are renamed by hand.
	input: data/{author_paper_academic_age.pkl, pid2author_list.pkl, pid2author_country_list.pkl, pid2field_of_study.pkl} (from get_author_academic_age.py / get_paper_meta.py), META_DIRE/efg_computation/gen_V3_y{year_offset}.csv and gen_V3_disp_f_y{year_offset}.csv (from get_efg_s2_merge.py), META_DIRE/disruption/disp_full{disp_year_tag}{disp_k_suffix}.csv (from arrange_disruption.py, same year_offset / k_require_after_focal), META_DIRE/efg_computation/efg_within_year_domain_quantile_y{year_offset}_rt_{reference_threshold}_ct_{citation_threshold}/*.csv (from compute_efg_quantile_by_domain.py; only when USE_QUANTILE)
	output (to ./figures/country_avg_age_vs_efg/): the 1x3 F/E/G figure and its caches are named after the panel at the deliverable setting USE_DISP_F=False, USE_QUANTILE=False, year_offset=5, reference_threshold=1, citation_threshold=5, SELECT_MAX_YEAR == MAX_YEAR (is_ed_fig) -> Extended Data Fig. 10b.svg/.png, Extended Data Fig. 10b.csv (per-country avg age + avg E/F/G), Extended Data Fig. 10b_disp.csv (the Generalization-panel disruption inset) and Extended Data Fig. 10b_regression.csv (the per-panel fits); MIN_INSTANCES is deliberately NOT part of that gate, so changing it overwrites the same files. Every other combination keeps the parameterized names country_avg_age_vs_efg_{agg_suffix}_mi{MIN_INSTANCES}{dispf_tag}{value_tag}.svg/.png with caches country_avg_age_efg_agg_*, country_avg_disp_agg_*, country_avg_age_vs_efg_regression_* (+ country_avg_dispf3_agg_*, USE_DISP_F only). The separate 1x4 (i+j+k) figure is NOT part of the deliverable and always keeps its parameterized names: country_avg_age_vs_ijk_{agg_suffix}_mi{MIN_INSTANCES}{disp_k_suffix}{value_tag}.svg/.png with caches country_avg_ijk_agg_* and country_avg_age_vs_ijk_regression_* (PLOT_IJK only)
