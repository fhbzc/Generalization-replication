plot_longitudional_change.py (Fig. 3a)
	description: Plots the longitudinal change of the E/F/G indices — Foundation (f_y), Extension (e_y), Generalization (g_y) — for OpenAlex vs WoS on one dual-axis figure (Foundation on the left axis; Extension/Generalization on the right), OpenAlex solid / WoS dashed, with vertical marker_years and a 3x2 legend inside the upper right. Both sources share the same schema and expose the already-normalized index shares (e_y/f_y/g_y = count/citation_count), so the indices are read directly (no recomputation). Both are filtered to pub_year >= 1945, up_refer_count >= reference_threshold and citation_count_y{activity_year} >= citation_threshold, with a SOURCE-SPECIFIC upper cutoff — OpenAlex pub_year < 2026 - activity_year, WoS pub_year < 2025 - activity_year — because the OpenAlex 2026 snapshot carries one year more than WoS. Yearly means per dataset are cached to CSV before drawing, and when BOTH caches exist they are loaded instead of the big gen_V3 tables (delete them to recompute). Loads THIS directory's utils.py explicitly by file path so it can never be shadowed by another utils module. The run at the paper's settings (activity_year=1, reference_threshold=1, citation_threshold=2) is the main-text deliverable and is singled out by the is_fig3a flag: the figure and the data table behind it are named after the panel, every other setting keeps the descriptive dynamic_feg_dual_axis_* name. The per-source yearly_avg_* caches are keyed by the thresholds only and are NOT renamed, so they stay shared across runs. The .csv is always the .svg name with the extension swapped, so the deliverable's data table carries the same figure label. activity_year must match the year_offset used when BOTH merges were run.
	input: OPENALEX_META/gen_V3_keep_disp/gen_V3_y{activity_year}.csv (from get_efg_2026_merge.py) + WOS_META/efg_computation/gen_V3_y{activity_year}.csv (from wos/get_efg_s2_merge.py); both are unfiltered concatenations — this script applies the rt / ct / pub_year thresholds itself
	output (to ./figures/wos_openalex_joint_pattern/): at the deliverable setting (is_fig3a) -> Fig. 3a.svg + Fig. 3a.csv (both sources' yearly means stacked, with a 'dataset' column of WoS / OpenAlex); every other setting keeps dynamic_feg_dual_axis_y{activity_year}_ref{reference_threshold}_cit{citation_threshold}.svg + its .csv. Plus the per-source caches yearly_avg_wos_y{activity_year}_ref{reference_threshold}_cit{citation_threshold}.csv and yearly_avg_openalex_y{activity_year}_ref{reference_threshold}_cit{citation_threshold}.csv, which keep their parameterized names in every run.


>>>>>>>>> Validation summary: every "desired vs undesired" gap on one axis

Prerequisites (run first; this script does NO computation of its own, it only reads their
gap CSVs, and every setting in its settings block exists solely to rebuild their filenames —
so each block must match that script's own parameters):
  - openalex/award_analysis/award_quantile_analysis.py
        -> figures/award_quantile_disp_f/q_{QUANTILE_GROUP}/award_quantile_gap_bootstrap_*.csv
           (supplies the Nobel Prize and Major award comparison groups)
  - wos/venue_validation/plot_annual_review_efgd_distribution.py
        -> figures/annual_review_efgd_ijratio/annual_review_gap_bootstrap_*.csv
           (Annual Review; NOTE reference is the DESIRED side, so the gap is Reference - Review)
  - semantic_scholar/academic_keyword_analysis/forecite_central_papers_efg_s2_plot.py
        -> figures/forecite_gt_{FORECITE_THRESHOLD}/gap_bootstrap_{value_tag}.csv
           (New-concept papers; FORECITE_DEFINITIONS picks which central-paper definitions
            become their own comparison group)
  IMPORTANT: all three must have been run at the SAME quantile grouping as QUANTILE_GROUP here,
  so every value is a within-(pub_year x domain) percentile rank and the gaps share one scale.
  Each gap CSV records the grouping it was built at, and a mismatch is reported rather than
  silently mixed.
  IMPORTANT too: all three must have been run at the same year_offset AND the same
  select_max_year as this script. Both are single GLOBAL settings here, deliberately: a bar
  chart that puts every validation on one axis is only meaningful if every source covers the
  same publication window. The settings block then derives each source's OWN max_year and
  rebuilds its filename, including whatever narrowing tag that source uses -- so a source that
  was run at a different cutoff shows up as a missing file (STRICT_MISSING) rather than as a
  bar silently measured over another population.

plot_validation_quantile_gap.py (Extended Data Fig. 5a-5b)
	description: One grouped bar chart per metric family summarising every "desired vs undesired" validation on a single axis. Each source script has already reduced its comparison to gap = mean quantile(desired) - mean quantile(undesired) plus a bootstrap 95% CI (computed where the per-paper values are: the two classes are independent samples, resampled 2000x, CI = 2.5/97.5 percentiles of mean(desired*) - mean(undesired*); a class over 200k papers — always the whole-corpus "undesired" baseline — instead draws replicate means from N(mean, s^2/n), and each row records which was used). This script concatenates the three CSVs (they share one schema and one set of canonical metric keys) and draws them. x = comparison group, colour = metric, so a group's bars cluster at its tick and read against each other; a positive bar means the desired class sits higher on that index, and Generalization / the disruption ratio are expected to go the other way — which is the point of drawing them. Each bar carries its CI as an error bar (DRAW_CI), so a bar whose interval clears 0 is the visible claim. Two families are drawn: 'fdg' (Foundation / Disruptive Foundation / Extension / Disruption Ratio / Generalization) and 'ijk' (F/(C+K) / Disp(F)/(C+K) / E/(C+K) / I/(C+K) / (I-J)/(C+K), where C = I+J). A metric no source reports yet (E/(C+K) until compute_*_quantile.py is re-run with that column) is dropped from its figure rather than left as an empty slot; colours are bound to the metric key, so dropping one does not recolour the others. STRICT_MISSING=True stops with the missing paths listed rather than quietly dropping a whole comparison group (a dropped bar is invisible in the finished figure, so silence is the dangerous default); a missing METRIC is only reported. Each source path is resolved at its canonical location first, then by a recursive search for the same basename under that project's figures/ directory, so files copied elsewhere are still found. Both charts at the paper's default settings are the Extended Data deliverable, singled out by the is_ed_fig flag (year_offset=5, QUANTILE_GROUP='year_domain', INCLUDE_DISP_F and INCLUDE_DISP both on, and select_max_year == max_year -- a narrowed period is a different comparison and a figure missing a metric family is not the deliverable): the fdg family becomes panel 5a and the ijk family panel 5b (ED_FIG_PANEL maps family -> panel name). The values CSV carries BOTH families — its rows have a 'family' column — so it is named for the figure as a whole, Extended Data Fig. 5.csv, rather than for either panel. CITATION WINDOW AND PERIOD: year_offset is global and max_year follows it -- 2025 - year_offset, or 2025 at year_offset == -1, where there is no elapsed window to leave room for. select_max_year is global too (<= max_year, asserted) and is the publication cutoff EVERY source is read at; leave it at max_year for no narrowing. Each source block then derives its own max_year and decides for itself whether its filename carries a narrowing tag, because that is the comparison the source script itself makes: award_quantile_analysis.py puts select_max_year (not max_year) in 'ybefore_' and adds '_full_cover' at year_offset == -1 plus '_multi_match' when it ran with require_unique_match = False (award_require_unique_match here); plot_annual_review_efgd_distribution.py puts select_max_year in its own 'ybefore_' and its OUTPUT names never carry the '_full_cover' tag (only its input does, so there is no wos_name_tag); forecite_central_papers_efg_s2_plot.py names everything by value_tag and appends '_ybefore_{select_max_year}' ONLY when it narrows, which is why the ForeCite tag is built by a function (_forecite_value_tag) called after that source's block is set. Two toggles drop a whole metric family from BOTH figures -- INCLUDE_DISP_F = False removes the disruptive-foundation bars (Disruptive Foundation and Disp(F)/(C+K)) and INCLUDE_DISP = False the disruption ones (Disruption Ratio and (I-J)/(C+K)) -- each adding its own filename suffix ('_nodispf' / '_nodisp'). This script needs no metadata root at all — every input is repo-local under some project's figures/.
	input (every path rebuilt from the settings block, so a source run at other settings fails as a missing file): openalex/award_analysis/figures/award_quantile_disp_f/q_{QUANTILE_GROUP}/award_quantile_gap_bootstrap_{award_param_suffix}.csv with award_param_suffix = y{year_offset}{award_data_suffix}_rt_{award_rt}_ct_{award_ct}_ybefore_{select_max_year}{award_name_tag}_q_{QUANTILE_GROUP}{award_match_tag}; wos/venue_validation/figures/annual_review_efgd_ijratio/annual_review_gap_bootstrap_{wos_out_param_suffix}.csv with wos_out_param_suffix = y{year_offset}{wos_data_suffix}{wos_k_suffix}_rt_{wos_rt}_ct_{wos_ct}_ybefore_{select_max_year}{wos_mode_suffix}_q_{QUANTILE_GROUP}; semantic_scholar/academic_keyword_analysis/figures/forecite_gt_{FORECITE_THRESHOLD}/gap_bootstrap_{value_tag}.csv with value_tag = quantile_{grouping} plus '_ybefore_{select_max_year}' when that script narrowed (the forecite_gt_ directory is tried at both spellings of an integer threshold, e.g. '2' and '2.0')
	output (to ./figures/validation_quantile_gap/; tag = y{year_offset}_ybefore_{select_max_year}_q_{QUANTILE_GROUP}{_nodispf}{_nodisp} -- both settings that define the population, the citation window and the publication cutoff, are in the name, so a narrowed run never lands on the un-narrowed one's files): at the deliverable setting Extended Data Fig. 5a.svg/.png (fdg family), Extended Data Fig. 5b.svg/.png (ijk family) and the shared Extended Data Fig. 5.csv; every other setting keeps quantile_gap_fdg_{tag}.svg/.png, quantile_gap_ijk_{tag}.svg/.png and quantile_gap_values_{tag}.csv. The CSV holds every bar's two class means, n's, gap and 95% CI for both panels, plus the bootstrap mode and seed each source used.

visualize_efg_obs_vs_single_iter_control_venue_combined.py (Fig. 3b)
	description: Combined OpenAlex + WoS version of the two per-dataset visualize_efg_obs_vs_single_iter_control_venue.py scripts: instead of two figures it draws ONE 1x3 grid (a panel per index) with both datasets and both conditions overlaid in every panel. Three visual channels carry the three distinctions — colour = index (Foundation red / Extension orange / Generalization blue), linestyle = dataset (OpenAlex solid / WoS dashed), linewidth = condition (Observed bold / Randomized thin) — with a single style legend in the first panel's upper right. Each panel plots the observed E/F/G share against one venue-controlled reshuffle iteration (the null model) as a trend over publication year. The per-dataset computation is identical to the two source scripts and is factored into compute_dataset(): load the merged tables, apply the pub_year window and the citation / reference thresholds, INTERSECT the threshold-passing pids across the observed run and every iteration (so observed and randomized are compared over an identical paper set), then average e/f/g per pub_year. The figure uses a single shared x-label ('Publication Year') and y-label ('Average index') via fig.supxlabel / supylabel rather than per-panel labels. This script does NOT read the standalone scripts' caches: on a first run it computes both datasets from the raw gen_V3 CSVs on the server and writes its OWN cache (one obs_agg / rand_agg pair per dataset, namespaced by dataset name and by a param_suffix carrying the iterations and thresholds); a redraw loads those local caches and never touches the big gen_V3 tables. Delete the cache CSVs or set force_recompute=True to recompute. year_offset / upper_year / iteration_list and the thresholds must match the merges that produced the inputs. The run at the paper's settings (year_offset=1, upper_year=2025, iteration_list=[0], reference_threshold=1, citation_threshold=2, wos_data_suffix='') is the main-text deliverable and is singled out by the is_fig3b flag: the figure AND the two per-dataset aggregate caches behind it are named after the panel instead of carrying the parameter stub, while every other setting keeps the descriptive names. The gate lists every parameter that changes what the panels show, so no other run can land on the name; a cache written under the older descriptive names is still loaded (and re-saved under the Fig. 3b names), so the rename never forces a recompute from the gen_V3 tables.
	input: META_DIRE_OA/efg_computation_control_venue/{gen_V3_y{year_offset}_obs_valid_primary_location_before_{upper_year}.csv, gen_V3_y{year_offset}_iter{it}_before_{upper_year}.csv} (from openalex/atypicality_control_venue/), WOS_META/efg_computation/gen_V3_y{year_offset}.csv (observed, from wos/get_efg_s2_merge.py) and WOS_META/efg_computation_control_venue/gen_V3_y{year_offset}_iter{it}_before_{upper_year}.csv (from wos/atypicality_control_venue/)
	output (to ./figures/atypicality_control_venue/): at the deliverable setting (is_fig3b) -> Fig. 3b.svg, plus the caches cached_data/Fig. 3b_obs_agg_{dataset}.csv and cached_data/Fig. 3b_rand_agg_{dataset}.csv for dataset in {openalex, wos}. Every other setting keeps the parameterized names: efg_obs_vs_{iter_tag}_ay{year_offset}_ct{citation_threshold}_rt{reference_threshold}_before_{upper_year}_combined.svg (iter_tag = 'iter' + the iteration_list joined by '-'), plus cached_data/{obs_agg,rand_agg}_{dataset}_{param_suffix}.csv (param_suffix = isect_{iter_tag}_ay{year_offset}_ct{citation_threshold}_rt{reference_threshold}_before_{upper_year}, with the WoS data_suffix appended on the WoS side)
