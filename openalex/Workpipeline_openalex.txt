get_citation_network_no_self_citation.py
	description: Rebuilds the citation network with all self-citations removed. Starting from the real network (citing pid -> cited pids) from get_meta_data_preprint.py, it drops every citing->cited edge whose two papers SHARE an author: each paper's author-id set comes from pid2author_list.pkl (get_meta_data_preprint_author_country_process.py); an edge is dropped only when BOTH papers have a non-empty identified author list AND those sets intersect, otherwise (no overlap, or either side has no identified authors) the edge is KEPT — papers with no identified authors are never treated as self-citing. The filtered citing->cited mapping is then inverted to rebuild a consistent, de-duplicated cited->citing mapping. Prints edge counts (total / kept / dropped-as-self-citation / kept-because-author-list-missing). utils.py is in this same directory.
	input: META_DIRE/citing_pid2cited_pids_list.pkl (from get_meta_data_preprint.py), META_DIRE/pid2author_list.pkl (from get_meta_data_preprint_author_country_process.py)
	output (to META_DIRE = data/): citing_pid2cited_pids_list_no_self_citation.pkl, cited_pid2citing_pids_list_no_self_citation.pkl

get_efg.py
	description: Computes the E/F/G generalization metrics for each focal paper over a year_offset-year citation window: for every citing paper, compares how many of the focal paper's references vs. its other citing papers that citing paper also cites (up vs down), tallying e (up>down), f (down>up), g (isolated, neither), with ties split 0.5/0.5. Also emits normalized shares e_y/f_y/g_y = e/f/g_count / citation_count (set to 0 when citation_count == 0). Normal mode only (real citation network); the reshuffled-network variant is atypicality/get_efg_reshuffle.py. Processed in 20 divisions with multiprocessing. The network_mode switch selects which citation network to compute on via NETWORK_SUFFIX_MAP: 'normal' (network_suffix='', full network from get_meta_data_preprint.py), 'no_self_citation' (network_suffix='_no_self_citation', self-citation-removed network from get_citation_network_no_self_citation.py), or 'no_year_filter' (network_suffix='_no_year_filter', temporally-unfiltered network from get_meta_data_preprint_no_year_filter.py). network_suffix tags every input/output filename so the variants never overwrite each other.
	input: data/pid2pub_year.pkl (from get_meta_data_preprint.py); citation network data/citing_pid2cited_pids_list{network_suffix}.pkl & data/cited_pid2citing_pids_list{network_suffix}.pkl (network_suffix='' -> full network from get_meta_data_preprint.py; '_no_self_citation' -> self-citation-removed network from get_citation_network_no_self_citation.py; '_no_year_filter' -> temporally-unfiltered network from get_meta_data_preprint_no_year_filter.py)
	output (to META_DIRE/efg_computation/): gen_V3_y{year_offset}{network_suffix}_d_{division_index}_max_{division_count}.csv, gen_V3_y{year_offset}{network_suffix}_finished_d_{division_index}_max_{division_count}.pkl (per-division marker); CSV columns: pid, pub_year, up_refer_count, citation_count_y{off}, e_count_y{off}, f_count_y{off}, g_count_y{off}, e_y{off}, f_y{off}, g_y{off}

(How widely the influence of top-ranked F/E/G papers spreads, measured on the CITING side and
 drawn as one point per (citation window x index): x = how MANY distinct groups the citations
 come from, y = how CONCENTRATED they are in the single largest group. Two parallel versions:

 Both share the same design -- process each citation window on its own, rank e/f/g only within
 (pub_year x domain-or-field) cells of that window so a paper is compared against same-year,

 that window and a redraw recomputes nothing.)
