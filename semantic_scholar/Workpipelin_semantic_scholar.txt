download_s2ag.py
	description: Downloads a Semantic Scholar Academic Graph (S2AG) dataset (e.g. "papers", "citations", "s2orc", ...) from the Semantic Scholar bulk-datasets API into S2AG_DIRE/<DATASET_NAME>/. Resolves the latest release id, fetches the dataset's list of file-shard URLs (authenticated with the API key), and downloads each shard with wget, skipping any already present so the download is resumable. Requires a Semantic Scholar API key (SEMANTIC_SCHOLAR_API_KEY env var or edit API_KEY); the downstream pipeline needs the "papers" and "citations" datasets (get_s2ag_meta.py / get_s2ag_citation.py) and the "s2orc" dataset (full_text_analysis/get_s2orc_meta.py). Run it once per dataset (set DATASET_NAME). This is the FIRST step — run it before get_s2ag_meta.py / get_s2ag_citation.py / get_s2orc_meta.py.
	input: Semantic Scholar bulk-datasets API (https://api.semanticscholar.org/datasets/v1/), requires an API key
	output (to S2AG_DIRE/<DATASET_NAME>/): the dataset's gzipped JSONL shards (e.g. S2AG_DIRE/papers/*.gz, S2AG_DIRE/citations/*.gz)


get_s2ag_meta.py
	description: Extracts per-paper metadata from the Semantic Scholar Academic Graph (S2AG) "papers" dump (gzipped JSONL shards, one paper per line). For each record (keyed by corpusid) it pulls publication year, publication date, title, and DOI (from externalids). Shards are split into 32 batches and processed in parallel (ProcessPoolExecutor, max_workers workers), and the per-shard dicts are merged.
	input: S2AG_DIRE/papers/*.gz (S2AG papers dump, downloaded by download_s2ag.py with DATASET_NAME="papers"; path configured as S2AG_DIRE in utils.py)
	output (to META_DIRE/): cid2pub_year.pkl, cid2pub_date.pkl, cid2title.pkl, cid2DOI.pkl

get_s2ag_meta_author_domain.py
	description: Extracts per-paper field-of-study categories and author counts from the S2AG "papers" dump (gzipped JSONL shards). For each record (keyed by corpusid) it collects the distinct s2fieldsofstudy categories and the number of authors, and builds the inverse category -> [corpusid] index (deduplicated). Shards are split into 32 batches and processed in parallel (ProcessPoolExecutor, max_workers workers), and the per-shard results merged.
	input: S2AG_DIRE/papers/*.gz (S2AG papers dump, downloaded by download_s2ag.py with DATASET_NAME="papers"; path configured as S2AG_DIRE in utils.py)
	output (to META_DIRE/): cid2category_list.pkl, cid2author_count.pkl, category2cid_list.pkl

get_s2ag_meta_author_domain_s2_simple_domain.py
	description: Extracts a SINGLE field-of-study category per paper from the S2AG "papers" dump -- the S2AG analogue of openalex/get_meta_data_preprint_review_s2_simple_concept.py. Same parsing as get_s2ag_meta_author_domain.py, but keeps exactly ONE of a paper's distinct s2fieldsofstudy categories: chosen at RANDOM when it has more than one (S2AG categories carry no score, so no highest-score rule; a single category is kept directly), or 'Others' when it has none. RNG seeded once (reproducibility not guaranteed). Shards processed in parallel and merged; skips entirely if the output already exists.
	input: S2AG_DIRE/papers/*.gz (S2AG papers dump; path configured as S2AG_DIRE in utils.py)
	output (to META_DIRE/): cid2single_concept.pkl (cid -> chosen category display name, or 'Others') + category2cid_list_single.pkl (category -> [cids], each cid under exactly ONE category)

get_s2ag_citation.py
	description: Builds the S2AG citation network (corpusid -> [corpusid]) from the S2AG "citations" dump (gzipped JSONL shards, one citation edge per line), restricted to "valid" papers — corpusids that have BOTH a publication year and a title (intersection of cid2pub_year and cid2title from get_s2ag_meta.py). The valid-cid set is cached to valid_cid_list.pkl and reused on later runs. Both directions of each kept edge are recorded and deduplicated.
	input: S2AG_DIRE/citations/*.gz (S2AG citations dump, downloaded by download_s2ag.py with DATASET_NAME="citations"; path configured as S2AG_DIRE in utils.py) + META_DIRE/{cid2pub_year.pkl, cid2title.pkl} (from get_s2ag_meta.py)
	output (to META_DIRE/): valid_cid_list.pkl (cached valid-cid set), cited2citing_cid_list.pkl, citing2cited_cid_list.pkl

get_s2ag_citation_s2_remove_circle.py
	description: Removes temporally-inconsistent ("circular") edges from the S2AG citation network (get_s2ag_citation.py). Using each paper's publication date (preferred) or year, an edge is kept only if its direction agrees with chronology — in cited2citing the citing paper must be published on/after the cited paper, in citing2cited the cited paper must be on/before the citing paper — and self-loops are dropped. When both endpoints have a date their dates are compared, otherwise it falls back to year.
	input: META_DIRE/{cid2pub_year.pkl, cid2pub_date.pkl} (from get_s2ag_meta.py) + META_DIRE/{cited2citing_cid_list.pkl, citing2cited_cid_list.pkl} (from get_s2ag_citation.py)
	output (to META_DIRE/): cited2citing_cid_list_remove_circle.pkl, citing2cited_cid_list_remove_circle.pkl

get_efg.py
	description: Computes the E/F/G generalization index for every S2AG paper from the temporally-consistent ("remove_circle") citation network, in per-division shards (resumable). For a focal paper P, over each paper C that cites P within year_offset years: up_count = |refs(P) & refs(C)|, down_count = |citers(P) & refs(C)|; tallies g (up==0 and down==0), e (up>down; a tie splits 0.5/0.5), f (up<down). The e/f/g SHARES are these counts / P's citation count (raw counts are also written). Paper ids are S2AG corpus ids kept in the 'pid' column. Papers are split into division_count divisions, each written to its own CSV + a finished-flag. use_openalex_augmented = True runs on the OpenAlex-augmented remove_circle network (network_suffix tags the filenames).
	input: META_DIRE/cid2pub_year.pkl (from get_s2ag_meta.py) + META_DIRE/{citing2cited_cid_list_remove_circle, cited2citing_cid_list_remove_circle}[_openalex_augmented].pkl (from get_s2ag_citation_s2_remove_circle.py, or augment_s2_citation_with_openalex.py)
	output (to META_DIRE/efg_computation/): per-division gen_V3_y{year_offset}[_openalex_augmented]_d_{division}_max_{division_count}.csv (+ ..._finished_... markers). Merge with get_efg_s2_merge.py.

get_efg_s2_merge.py
	description: Concatenates the per-division E/F/G CSVs into a single table -- no filtering here (downstream applies its own pub_year / reference / citation thresholds). use_disp_f selects which shards to merge: False -> get_efg.py (gen_V3_y{off}...), True -> get_efg_v2_disp_f.py (gen_V3_disp_f_y{off}..., with the three disp_f columns). use_openalex_augmented must match get_efg.py / get_efg_v2_disp_f.py (network_suffix encodes the network in the filenames).
	input: META_DIRE/efg_computation/gen_V3[_disp_f]_y{year_offset}[_openalex_augmented]_d_{division}_max_{division_count}.csv (+ ..._finished_... markers; from get_efg.py / get_efg_v2_disp_f.py)
	output (to META_DIRE/efg_computation/): gen_V3[_disp_f]_y{year_offset}[_openalex_augmented].csv

get_efg_v2_disp_f.py
	description: Same as get_efg.py (E/F/G over the S2AG remove_circle network, per-division shards) but ALSO computes the three "disruptive foundation" (disp_f) variants in one pass: a citing paper C of focal P counts as disruptive-foundation when it shares NONE of P's references (up_count == 0) yet co-cites more than T of P's other citers (down_count > T), for T = 0 (down>0, the original disruption_f), 1 (down>1), 2 (down>2). Writes both counts and shares. Paper ids kept in the 'pid' column. Merge with get_efg_s2_merge.py (use_disp_f=True). use_openalex_augmented tags the network variant via network_suffix.
	input: META_DIRE/cid2pub_year.pkl (from get_s2ag_meta.py) + META_DIRE/{citing2cited_cid_list_remove_circle, cited2citing_cid_list_remove_circle}[_openalex_augmented].pkl (from get_s2ag_citation_s2_remove_circle.py, or augment_s2_citation_with_openalex.py)
	output (to META_DIRE/efg_computation/): per-division gen_V3_disp_f_y{year_offset}[_openalex_augmented]_d_{division}_max_{division_count}.csv (+ ..._finished_... markers). Merge with get_efg_s2_merge.py.

compute_efg_quantile.py
	description: S2AG version of openalex/compute_efgd_quantile.py. From the merged gen_V3[_disp_f] table, computes per-paper quantiles of each E/F/G (+ disp_f) index and the citation count -- and, with disp_f, the DERIVED disruptive-citation fraction R = I/(I+J) = ij_ratio = g share + disp_f_0 share -- three ways: within (pub_year, top_concept) -> {col}_quantile (papers WITH a top domain only), within pub_year -> {col}_quantile_by_year (ALL papers), and globally -> {col}_quantile_global (ALL papers). The "top domain" comes from concept_source: 'single' (default) uses cid2single_concept.pkl (one category per cid, or 'Others'/absent -> NaN) so there is NO multi-domain case; 'list' uses cid2category_list.pkl (only exactly-one-category papers get a domain). Quantiles are computed only over papers passing the reference / citation / pub_year filters.
	input: META_DIRE/efg_computation/gen_V3[_disp_f]_y{year_offset}{network_suffix}.csv (from get_efg_s2_merge.py) + META_DIRE/cid2single_concept.pkl (get_s2ag_meta_author_domain_s2_simple_domain.py; concept_source='single') OR cid2category_list.pkl (get_s2ag_meta_author_domain.py; concept_source='list')
	output (to META_DIRE/efg_computation/, TWO files, one per pub_year cutoff): efg_within_year_domain_quantile_y{year_offset}{network_suffix}_rt_{rt}_ct_{ct}_ybefore_{2025 - year_offset}.csv (complete-window papers) + ..._ybefore_2025_full_cover.csv (all papers before 2025); each carries the raw indices + ij_ratio and the three quantile groupings per column.

	- full_text_analysis

		get_s2orc_meta.py
			description: Extracts per-paper full-text metadata from the Semantic Scholar S2ORC dump (gzipped JSONL shards under S2AG_DIRE/s2orc). For each paper that has a DOI and a unified `content` block, it parses the section headers and the in-text reference (bibref) instances, attaching each reference's DOI and venue from the bibliography (bibentry/bibvenue) annotations (positions index into content.text). 			input: S2AG_DIRE/s2orc/*.gz (S2ORC full-text dump, downloaded by download_s2ag.py with DATASET_NAME="s2orc"; path configured as S2AG_DIRE in utils.py)
			output (to S2ORC_META_DIRE/meta_batched_v2/reference/): per-batch DOI2section_header_list_b_<batch>_total_<N>.pkl, DOI2refer_instance_list_b_<batch>_total_<N>.pkl, and batch_<batch>_total_<N>_finished.pkl resume markers

		get_s2orc_meta_merge.py
			description: Merges the per-batch S2ORC full-text metadata written by get_s2orc_meta.py into two single pickles. Reads every batch's section-header and reference-instance pickles (asserting each batch's finished-flag exists), drops the now-unneeded 'end' offset from each reference instance, and concatenates across all batches.
			input: S2ORC_META_DIRE/meta_batched_v2/reference/ {DOI2section_header_list_b_<batch>_total_<N>.pkl, DOI2refer_instance_list_b_<batch>_total_<N>.pkl} (from get_s2orc_meta.py)
			output (to S2ORC_META_DIRE/): DOI2section_header_list_V2.pkl, DOI2refer_instance_list_V2.pkl

		identify_paper_template.py
			description: Identifies each paper's canonical section "template" from its S2ORC section headers. Only TOP-LEVEL (level-1) headers participate (sub-sections and "journal of ..." leaks dropped, duplicate same-start/title headers collapsed); a paper is KEPT iff its top-level titles contain, in document order, the five canonical sections intro -> method -> result -> discussion -> conclusion (keyword match; a merged "Results and Discussion" header fills both slots). Kept papers yield a fixed-order length-5 section list (index 1 == method, with the conclusion region's end carried on the conclusion entry); rejected papers are bucketed by reason (empty_sections / missing_intro / missing_method / ...).
			input: S2ORC_META_DIRE/DOI2section_header_list_V2.pkl (from get_s2orc_meta_merge.py)
			output (to S2ORC_META_DIRE/): DOI2parsed_section_seperator_V2.pkl + analysis_V2/template_rejected/rejected_<reason>_V2.jsonl (per-reason rejected-paper samples)

		identify_citation_property.py
			description: Classifies each S2ORC in-text reference instance into an E/F/G citation type plus a disruptive/non_disruptive axis, using the de-circularized S2AG citation network. Maps focal (citing) and cited papers to corpusids via DOI (keeping DOIs that map to exactly one corpusid), then for a focal paper A citing B computes up_count=|up(A)&up(B)| and down_count=|up(A)&down(B)|: disruptive=up_count==0; g=up&down both 0, f=down>=up>0, e=down<up. Only references B that are among A's recorded references are kept (rest counted as errors); each kept instance is tagged with cid, efg_type, disp_type, and the citing paper's publication year.
			input: META_DIRE/{cid2DOI.pkl, cid2pub_year.pkl, citing2cited_cid_list_remove_circle.pkl, cited2citing_cid_list_remove_circle.pkl} (from get_s2ag_meta.py / get_s2ag_citation_s2_remove_circle.py) + S2ORC_META_DIRE/DOI2refer_instance_list_V2.pkl (from get_s2orc_meta_merge.py)
			output (to S2ORC_META_DIRE/): DOI2refer_instance_list_cid_parsed_V2.pkl

		get_refer_mention_position.py
			description: Builds per-citation mention-position records for both classification systems (efg and disp) at once. Using the parsed canonical section separators, the document is partitioned into regions (before_intro / intro / method / result / res_dis / discussion / conclusion / after_conclusion) and each in-text reference is assigned to the region whose canonical-section start is the largest <= its offset (bisect); merged "Results and Discussion" sections become 'res_dis', and offsets at/after conclusion_end become 'after_conclusion'. Per citation it records efg, disp, cited cid, citing year, and a {mention_position: frequency} map.
			input: S2ORC_META_DIRE/{DOI2parsed_section_seperator_V2.pkl (from identify_paper_template.py), DOI2refer_instance_list_cid_parsed_V2.pkl (from identify_citation_property.py)}
			output (to S2ORC_META_DIRE/): refer_mention_records_V2.pkl (flat list of per-citation record dicts)

		analyze_refer_mention_position.py
			description: Aggregates mention-position stats for both classification systems (efg: e/f/g; disp: disruptive/non_disruptive) — OVERALL and PER cited-paper domain. For each panel (Frequency + each mention position: before_intro/intro/method/result/res_dis/discussion/conclusion/after_conclusion) it computes per-type means and all pairwise two-sided Welch t-tests. Domains come from the cited paper's cid via cid2category_list.pkl (normalised 'And'->'and'); a citation with multiple cited-paper domains contributes to each, and per-domain a type needs >= MIN_CITATIONS_PER_DOMAIN (5) records to be reported.
			input: S2ORC_META_DIRE/refer_mention_records_V2.pkl (from get_refer_mention_position.py) + META_DIRE/cid2category_list.pkl (from get_s2ag_meta_author_domain.py)
			output (to S2ORC_META_DIRE/analysis_V2/): efgd_full_stats.csv (overall) + efgd_by_domain/<domain>_stats.csv (one per domain)

		plot_refer_mention_position.py (Fig. 2g)
			description: Draws the E/F/G/D paneled bar figure of mention-position ratios + mention frequency (style of openalex/nlp_citation_purpose_measure/efg_citation_purpose_s2_plot.py): one panel each for Frequency / Introduction / Method / Result / Result&Discussion / Discussion, bars over F/E/G/D (D=disruptive, drawn with a hatch), each bar carrying a 95% CI whisker computed from the per-(panel, type) mean/var/n in the stats CSV (mean +/- 1.96*sqrt(var/n); a CSV predating the 'var' column simply gets no whisker, so re-run analyze_refer_mention_position.py if the whiskers are missing). There are NO pairwise-comparison brackets, and a single shared 'Citation type' x-label sits under all panels. Renders one OVERALL figure plus one per cited-paper domain. (Conclusion / before_intro / after_conclusion are in the CSV but not plotted.) Two toggles select what is drawn and must match the analyze_refer_mention_position.py run: REQUIRE_REFS reads the "papers must have references" stats (input dir and figure dir both suffixed '_hasref'), and INCLUDE_DISP_F appends the three disruptive-foundation variants Df>0/Df>1/Df>2 as extra hatched bars (outputs suffixed '_dispf'), so every combination coexists. 			input: S2ORC_META_DIRE/analysis_V2{_hasref}/efgd_full_stats.csv + analysis_V2{_hasref}/efgd_by_domain/<domain>_stats.csv (from analyze_refer_mention_position.py, same REQUIRE_REFS)
			output (to ./figures/refer_mention_position{_hasref}/ next to the script): at the deliverable setting (is_fig2g) -> Fig. 2g.svg/.png (overall); every other setting -> efgd_mention_position{_dispf}.svg/.png (overall). Per domain, always by_domain/<domain>{_dispf}.svg/.png

	- academic_keyword_analysis

		get_s2ag_meta_abs.py
			description: Extracts per-paper abstracts from the S2AG "abstracts" dump (gzipped JSONL shards, one record per line keyed by corpusid), grouped by publication year. A record is kept only if its corpusid has a known publication year (cid2pub_year) in [1951, 2025] and a non-empty abstract. Shards are processed in parallel (ProcessPoolExecutor, max_workers workers) and merged into a per-year corpusid -> abstract map. Directories come from utils.py (S2AG_DIRE / META_DIRE).
			input: S2AG_DIRE/abstracts/*.gz (S2AG abstracts dump, downloaded by download_s2ag.py with DATASET_NAME="abstracts"; path configured as S2AG_DIRE in utils.py) + META_DIRE/cid2pub_year.pkl (from get_s2ag_meta.py)
			output (to META_DIRE/cid2abs_year/): one pickle per publication year cid2pub_date_y_<year>.pkl, each mapping corpusid -> abstract for papers published that year

		get_global_trigam_bigram_s1_eng.py
			description: Builds per-year English unigram / bigram / trigram frequency tables from paper title+abstract text. For each publication year it loads that year's abstracts (cid2abs_year), forms "title abstract" text per paper, keeps only English text (fastText lid.176 language id), lemmatizes with spaCy (dropping stopwords / punctuation / spaces / single non-digit chars and splitting token runs at those breaks), and counts single tokens, bigrams, and trigrams (each trigram keyed as the pair of adjacent bigrams). Language detection and spaCy lemmatization run in parallel; a per-year finished-flag makes the job resumable.
			input: META_DIRE/{cid2title.pkl, cid2pub_year.pkl} (from get_s2ag_meta.py) + META_DIRE/cid2abs_year/cid2pub_date_y_<year>.pkl (from get_s2ag_meta_abs.py) + a fastText language-id model (lid.176.bin, path configured as LANG_DETECT_MODEL in utils.py) + spaCy en_core_web_sm
			output (to META_DIRE/global_tribigram_eng/): per year single_token2fre_y_<year>.pkl, bigram_token2fre_y_<year>.pkl, trigram_token2fre_y_<year>.pkl, cid2parsed_token_list_<year>.pkl, and finished_y_<year>.pkl resume markers

		get_global_trigam_bigram_s2.py
			description: Aggregates the per-year unigram / bigram frequency tables from get_global_trigam_bigram_s1_eng.py across all years (start_year..end_year, asserting each year's finished-flag), then scores bigram collocations by PMI (pointwise mutual information): for a bigram (w1, w2) PMI = log2(f(w1,w2) * total_single / (f(w1) * f(w2))). Only bigrams whose two components and joint frequency are all > 10 and whose PMI > PMI_bigram are kept. (Trigrams are not computed.) Directories come from utils.py (META_DIRE).
			input: META_DIRE/global_tribigram_eng/{single_token2fre_y_<year>.pkl, bigram_token2fre_y_<year>.pkl, finished_y_<year>.pkl} (from get_global_trigam_bigram_s1_eng.py)
			output (to META_DIRE/global_tribigram_eng/): valid_bigram2pmi_t_<PMI_bigram>_b_<start_year>_e_<end_year>.pkl; plus inspection CSV under ./bi_trigam_inspect/bigram_PMI_t_<PMI_bigram>_b_<start_year>_e_<end_year>.csv

		-- ForeCite academic-keyword extraction (King, Downey & Weld, "High-Precision Extraction of Emerging Concepts from Scientific Literature", SIGIR 2020 / arXiv 2006.06877). Candidate phrases = the single grams from get_global_trigam_bigram_s1_eng.py + the PMI-valid bigrams from get_global_trigam_bigram_s2.py (bigrams only; trigrams are not used); each is scored by its term citation graph and the ranked survivors are the academic keywords. Run s1 -> s2 -> s3 -> s4; then, optionally, the inspection/analysis scripts forecite_sample_keyword_central_papers.py and forecite_central_papers_efg_distribution.py.

		forecite_s1_paper_terms.py
			description: Stage 1/4. For each publication year, derives every paper's set of CANDIDATE TERMS from its lemmatized token stream (cid2parsed_token_list from get_global_trigam_bigram_s1_eng.py): every single lemma, plus each adjacent pair that is a valid bigram (valid_bigram2pmi from get_global_trigam_bigram_s2.py). Trigrams are not used. Also tallies each term's per-year document frequency. Per-year finished-flag makes it resumable. Directories come from utils.py (META_DIRE).
			input: META_DIRE/global_tribigram_eng/{cid2parsed_token_list_<year>.pkl (from get_global_trigam_bigram_s1_eng.py), valid_bigram2pmi_t_<PMI_bigram>_b_<VOCAB_START_YEAR>_e_<VOCAB_END_YEAR>.pkl (from get_global_trigam_bigram_s2.py)}
			output (to META_DIRE/academic_keyword_forecite/, pmi_tag = pmib_<PMI_bigram>): per year cid2term_set_y_<year>_<pmi_tag>.pkl (cid -> candidate terms), term2df_y_<year>_<pmi_tag>.pkl (term -> #papers that year), finished_s1_y_<year>_<pmi_tag>.pkl

		forecite_s2_central_counts.py
			description: Stage 2/4. Aggregates the stage-1 per-year outputs and walks the de-circularized citation network to build the ForeCite ingredients. term2year2count[t][year] = #papers mentioning t per year. term_central2count[t][p] = f^p_t : counted edge-wise -- for every citation edge q -> p, each term shared by BOTH q and p (so p is in the term's citation graph and q is a mentioning citer) increments (t, p). Also records cid2indegree[p] = #papers citing p. Candidate terms are restricted to total document frequency >= MIN_TERM_DF (set 1 to keep all). Directories come from utils.py (META_DIRE).
			input: META_DIRE/academic_keyword_forecite/{term2df_y_<year>_<pmi_tag>.pkl, cid2term_set_y_<year>_<pmi_tag>.pkl} (from forecite_s1_paper_terms.py) + META_DIRE/citing2cited_cid_list_remove_circle.pkl (from get_s2ag_citation_s2_remove_circle.py)
			output (to META_DIRE/academic_keyword_forecite/, tag = <pmi_tag>_df_<MIN_TERM_DF>_b_<begin>_e_<finish>): term2year2count_<tag>.pkl, term_central2count_<tag>.pkl, cid2indegree_<tag>.pkl, candidate_terms_<tag>.pkl

		forecite_s3_score_extract.py
			description: Stage 3/4. Computes the per-term ForeCite score in a CHECKPOINTED, RESUMABLE way; the final table assembly is left to forecite_s4_combine.py. For term t, over each candidate central paper p with >= MIN_CITATIONS (indegree) citations: f^p_t = term_central2count[t][p], f_t = #papers mentioning t published from pub_year(p) onward (exact suffix sum of term2year2count), score_p = log(f^p_t + 1) * (f^p_t / f_t); ForeCite(t) = max_p score_p. Only terms with >= MIN_CENTRAL_PAPERS candidate central papers are kept, then split in a STABLE order into N_LISTS contiguous lists; each list is scored independently (fanned out over PROCESS_COUNT fork workers) and checkpointed to list_<i>.pkl + a list_<i>_finished marker, so a rerun resumes from the unfinished lists. Directories come from utils.py (META_DIRE).
			input: META_DIRE/academic_keyword_forecite/{term2year2count_<tag>.pkl, term_central2count_<tag>.pkl, cid2indegree_<tag>.pkl} (from forecite_s2_central_counts.py) + META_DIRE/cid2pub_year.pkl (from get_s2ag_meta.py)
			output (to META_DIRE/academic_keyword_forecite/forecite_s3_partial/<out_tag>/, out_tag = <tag>_mcp_<MIN_CENTRAL_PAPERS>): per-list list_<i>.pkl (holding {'fc': word->score, 'pid': word->{pid:score_p}, 'det': word->detail}) + list_<i>_finished markers (i = 0 .. N_LISTS-1). No final table here -- run forecite_s4_combine.py next.

		forecite_s4_combine.py
			description: Stage 4/4. Unions the per-list partial results from forecite_s3_score_extract.py (every one of the N_LISTS lists must be finished) in list-index order into the TWO deliverable dicts + a readable ranked CSV. Optionally applies MIN_SCORE (floor on a word's max score) and/or TOP_K (an extra top-K CSV). word2forecite_score[w] == max(word2pid2forecite_score[w].values()). Directories come from utils.py (META_DIRE).
			input: META_DIRE/academic_keyword_forecite/forecite_s3_partial/<out_tag>/{list_<i>.pkl, list_<i>_finished} (i = 0 .. N_LISTS-1; from forecite_s3_score_extract.py)
			output (to META_DIRE/academic_keyword_forecite/, out_tag = <tag>_mcp_<MIN_CENTRAL_PAPERS>): word2forecite_score_<out_tag>.pkl (word -> ForeCite score == final dict 1) + word2pid2forecite_score_<out_tag>.pkl (word -> {pid: score_p}, every pid with score_p > 0 == final dict 2) + academic_keyword_list_<out_tag>.csv (readable ranking: rank, keyword, type, forecite_score, best_central_cid, f_p_t, f_t, df, n_pids_scored); optional academic_keyword_list_<out_tag>_top<TOP_K>.csv

		forecite_sample_keyword_central_papers.py
			description: Sanity/inspection over the ForeCite deliverables (forecite_s4_combine.py). Emits TWO keyword tables -- a RANDOM sample of SAMPLE_N keywords (fixed SEED) and the TOP_N keywords by max ForeCite score. Per keyword it reports the ForeCite score, the MAX-score paper (the ForeCite "central" paper), the EARLIEST-published scoring paper, the EARLIEST paper strictly above the keyword's mean score, and the top-K scoring papers, each with score + publication date/title (dates from cid2pub_date, falling back to cid2pub_year). Lets you eyeball whether a keyword's top / above-mean paper is an early, introducing paper. (A "pid" is a corpusid.)
			input: META_DIRE/academic_keyword_forecite/{word2forecite_score_<out_tag>.pkl, word2pid2forecite_score_<out_tag>.pkl} (from forecite_s4_combine.py, out_tag = <tag>_mcp_<MIN_CENTRAL_PAPERS>) + META_DIRE/{cid2pub_date.pkl, cid2pub_year.pkl, cid2title.pkl} (from get_s2ag_meta.py)
			output (to ./ next to this script): sampled_keyword_central_papers_<out_tag>_n<SAMPLE_N>_seed<SEED>.csv (random sample) + top_keyword_central_papers_<out_tag>_top<TOP_N>.csv (top by max score)

		forecite_central_papers_efg_s1_split.py
			description: STEP 1 of 2 (step 2 is forecite_central_papers_efg_s2_plot.py). Decides WHICH papers are "central" for the ForeCite keywords and caches the answer; it does no plotting and never touches the efg table. Takes every keyword with ForeCite score > FORECITE_THRESHOLD (CLI arg 1) and picks that keyword's central papers in FOUR ways, each yielding its own central class: max_score (the single highest-scoring paper), top5_score (its top TOP_K_PAPERS), earliest (the earliest-published paper among those scoring the keyword at all), earliest_above_mean (the earliest-published paper among those scoring ABOVE that keyword's mean -- one paper, not the whole above-mean set). Three of the four therefore contribute at most ONE paper per keyword; only top5_score contributes several. Each set is a UNIQUE union over keywords. Also saved is scored_pids -- every paper scoring ANY above-threshold keyword -- which step 2 and the regression use for REST_UNIVERSE='scored'. The build is the expensive part (a pure-Python loop over every keyword), so the cache is keyed ONLY by what the sets actually depend on (threshold, out_tag, TOP_K_PAPERS): step 2's plotting parameters are deliberately not part of that key, so re-running step 2 with different metrics / quantiles / select_max_year never invalidates it.
			input: META_DIRE/academic_keyword_forecite/{word2forecite_score_<out_tag>.pkl, word2pid2forecite_score_<out_tag>.pkl} (from forecite_s4_combine.py; out_tag = <tag>_mcp_<MIN_CENTRAL_PAPERS>) + META_DIRE/{cid2pub_date.pkl, cid2pub_year.pkl} (from get_s2ag_meta.py, for the two "earliest" definitions)
			output (to ./figures/forecite_gt_<threshold>/): central_sets_<out_tag>.pkl ({'key', 'central_sets': definition -> set(pid), 'scored_pids', 'n_keywords'}) + central_set_sizes_<out_tag>.csv (one row per definition: how many papers ended up central)

		forecite_central_papers_efg_s2_plot.py
			description: STEP 2 of 2. Reads step 1's cached central sets (a missing or mis-keyed cache is an error telling you to run step 1 with the same FORECITE_THRESHOLD / TOP_K_PAPERS / out_tag), looks the papers up in the S2AG quantile table and draws the central-vs-other index distributions. Per definition TWO 1x4 figures: F / Disruptive Foundation / I(I+J) disruption ratio / G, and the (C+K)-denominator row f/(C+K) / disp_f/(C+K) / i/(C+K) / (I-J)/(C+K) (C = I+J, so C+K is the I+J+K denominator). Both mirror openalex/award_analysis/award_quantile_analysis.py's combined figures: overlaid KDE curves, a dashed mean line per class and a coloured in-place "<class>\nmean=..." label beside it instead of a boxed legend ("Papers of new concept" vs "Others"), per-panel subtitles, one shared "Index quantile" x-label and one shared "Density" y-label. REST_UNIVERSE picks the comparison class: 'all_efg' = every other paper in the efg table, 'scored' = only the other ForeCite-scored papers. USE_QUANTILE / quantile_kind pick the plotted value ('' = within (year, domain), '_by_year', '_global', or the raw fractions). SELECT_MAX_YEAR: select_max_year (<= max_year, asserted) narrows the LOADED table to pub_year < select_max_year, applied by apply_select_max_year() to BOTH loads -- the KDE table and the gap/bootstrap table. The quantiles are NOT recomputed, so a second assert refuses the narrowing unless it is a within-year ranking (quantile_kind '' or '_by_year') or USE_QUANTILE is off; a '_global' rank was computed against the years now dropped. A narrowed run appends '_ybefore_{select_max_year}' to value_tag, which names every figure, CSV and cache, and select_max_year is part of the KDE cache key, so a narrowed run never reuses or overwrites the full one; with select_max_year == max_year the names are unchanged. NOTE max_year here is typed as 2025 - year_offset and must match the compute_efg_quantile.py file being read (that script writes one file per pub_year cutoff in its max_years list), so it is the INPUT file's cutoff, while select_max_year is the population actually analysed.
			input: ./figures/forecite_gt_<threshold>/central_sets_<out_tag>.pkl (from forecite_central_papers_efg_s1_split.py) + META_DIRE/efg_computation/efg_within_year_domain_quantile_y{year_offset}{network_suffix}_rt_{reference_threshold}_ct_{citation_threshold}_ybefore_{max_year}{name_tag}.csv (from compute_efg_quantile.py; F / disp_f / ij_ratio / G, the three (i+j+k) ratios and the disruption index D, raw + quantile columns per pid; pub_year is read as well when select_max_year narrows)
			output (to ./figures/forecite_gt_<threshold>/), with value_tag = quantile{quantile_kind or '_year_domain'} | 'raw', plus '_ybefore_{select_max_year}' when narrowed: dist_<definition>_<value_tag>.svg/.png (the F/disp_f/ratio/G 1x4) and dist_ijk_<definition>_<value_tag>.svg/.png (the (C+K) 1x4), one pair per definition; sample_counts_<value_tag>.csv (per setting x metric x group: the sample count n and the mean); gap_bootstrap_<value_tag>.csv (no figure -- per setting x metric the central/rest means, their difference and a bootstrap 95% CI of it, read by combine_wos_openalex/plot_validation_quantile_gap.py; covers more metrics than the figures: Extension, and E/(C+K) when the quantile table has it) + gap_bootstrap_key_<value_tag>.pkl (its config key, so a redraw with the same settings need not re-read the quantile table); hist_cache_<value_tag>.pkl (the KDE curves, cached PER METRIC so adding a metric only builds the new ones)
