get_meta_data.py
	description: Builds the Web of Science (WoS) paper-metadata and citation-network tables. From the WoS papers parquet shards (journal articles only) it records each paper's title, publication year, and macro citation topic(s) (split on ';'; papers with no topic -> 'Others'); then from the references parquet shards it builds the directed citation network, keeping only edges between known papers and dropping temporally-inconsistent ones (citing year >= cited year). Both stages run in parallel over the shards (ProcessPoolExecutor) and are skipped if their outputs already exist. WoS ids are stored with the 'WOS:' prefix stripped.
	input: WOS_DIRE/wos_papers.parquet/*.parquet & WOS_DIRE/wos_references.parquet/*.parquet (EXTERNAL WoS dataset, NOT produced by this pipeline; path configured as WOS_DIRE in utils.py)
	output (to META_DIRE/): pid2title.pkl, pid2pub_year.pkl, concept2pid_list.pkl, cited_pid2citing_pids_list.pkl, citing_pid2cited_pids_list.pkl

>>>>>>>>>  Compute F, E, G index

get_efg.py
	description: Computes the E/F/G generalization index for every WoS paper directly from the WoS citation network (built by get_meta_data.py), in per-division shards. For a focal paper P (pub year in [1945, max_year)) it looks at the papers citing P within year_offset years (year_offset == -1 disables the window); for each citing paper C it compares up_count=|refs(P)&refs(C)| and down_count=|citers(P)&refs(C)|, tallying g (both 0), e (up>down), f (up<down), splitting a tie 0.5/0.5. Per paper it writes counts and citation-normalised e/f/g shares. Divisions run optionally over process_count workers, each written to its own CSV with a finished-flag (resumable). The use_with_review switch sets data_suffix: when True ('_with_review') it reads the get_meta_data_with_review.py outputs (citation network that also keeps doctypes=='review') and tags every input/output filename with that suffix; when False ('') it uses the article-only get_meta_data.py outputs. The two variants never overwrite each other.
	input: META_DIRE/{pid2pub_year{data_suffix}.pkl, citing_pid2cited_pids_list{data_suffix}.pkl, cited_pid2citing_pids_list{data_suffix}.pkl} (data_suffix='' from get_meta_data.py; data_suffix='_with_review' from get_meta_data_with_review.py)
	output (to META_DIRE/efg_computation/): per-division gen_V3_y{year_offset}{data_suffix}_d_{division}_max_{division_count}.csv + ..._finished_..._.pkl markers

get_efg_s2_merge.py
	description: Concatenates the per-division E/F/G CSVs from get_efg.py into one table (asserting every division's finished-flag + CSV exist), with no filtering — downstream scripts apply their own pub_year/reference/citation thresholds. year_offset and division_count must match get_efg.py. The use_with_review switch must also match get_efg.py: it sets data_suffix ('' for the article-only network, '_with_review' for the review-inclusive network), which selects the per-division inputs and tags the merged output, so the two variants never collide.
	input: META_DIRE/efg_computation/gen_V3_y{year_offset}{data_suffix}_d_{division}_max_{division_count}.csv (+ ..._finished_... markers, from get_efg.py, same use_with_review)
	output (to META_DIRE/efg_computation/): gen_V3_y{year_offset}{data_suffix}.csv

arrange_efg_by_domain.py
	description: Splits the merged per-paper E/F/G table (get_efg_s2_merge.py) into one CSV per domain. Loads concept2pid_list.pkl (domain -> [pid], from get_meta_data.py) and, for each domain, keeps the rows of gen_V3_y{year_offset}.csv whose 'pid' belongs to that domain (a paper in several domains appears in each), writing a per-domain CSV. Resumable via a per-domain finished-flag; year_offset must match get_efg.py / get_efg_s2_merge.py.
	input: META_DIRE/concept2pid_list.pkl (domain -> [pid], from get_meta_data.py) + META_DIRE/efg_computation/gen_V3_y{year_offset}.csv (from get_efg_s2_merge.py)
	output (to META_DIRE/efg_computation/efg_by_domain/<domain>/): efg_<domain>_y{year_offset}.csv (+ efg_arrange_finished.pkl markers)

- atypicality_control_venue
	filter_network_valid_source_title.py
		description: Builds the venue-filtered citation network the whole control-venue pipeline runs on -- the WoS twin of the OpenAlex filter_network_valid_primary_location.py, with the journal source_title string standing in for the primary_location source id. A pid is VALID iff pid2source_title{data_suffix}.pkl gives it a non-None, non-empty source_title that is NOT in the in-script FILTER_SOURCE_TITLES exclusion set; for each of the two adjacency dicts an edge (k, n) is kept only when BOTH endpoints are valid (invalid keys dropped, invalid neighbours filtered out, keys left with an empty list dropped). Reports keys kept and edges before/after, and skips an output that already exists. FILTER_SOURCE_TITLES is EMPTY by default: WoS get_meta_data.py already restricts the network to journal articles, so the preprint/repository venues the OpenAlex version excludes (arXiv, bioRxiv, SSRN, PubMed, ...) never appear here -- the mechanism is kept only so a venue can be dropped later without a code change. It also writes a per-venue paper-count CSV (counted over every paper with a non-empty source_title, BEFORE the exclusion filter, sorted by descending count) so the table can be inspected to decide what to exclude. utils.py is imported from the parent (wos/) directory.
		input: META_DIRE/pid2source_title{data_suffix}.pkl (from venue_validation/get_meta_data_get_venue.py) + META_DIRE/{citing_pid2cited_pids_list{data_suffix}.pkl, cited_pid2citing_pids_list{data_suffix}.pkl} (from get_meta_data[_with_review].py)
		output (to META_DIRE/): source_title2paper_count{data_suffix}.csv (source_title, paper_count), citing_pid2cited_pids_list_valid_source_title{data_suffix}.pkl, cited_pid2citing_pids_list_valid_source_title{data_suffix}.pkl

	network_reshuffle_efficient_control_venue.py
		description: Venue-controlled degree-preserving reshuffle (Uzzi et al., Science 2013) of the venue-filtered network. Edges are reshuffled by target swaps ((s1,t1),(s2,t2) -> (s1,t2),(s2,t1), ~2*E*ln(E) attempts per block via reshuffle_network_approx, self-loops and same-source pairs skipped), but the stratification block key is extended from (source_year, target_year) to (source_year, source_venue, target_year, target_venue) and swaps only ever happen WITHIN one block. Consequently every source keeps its out-degree and venue, every target keeps its in-degree and is only ever exchanged with a target of the same year AND venue, and the edge count of each (source_venue -> target_venue) pair within each (source_year, target_year) cell is exactly preserved. Only citing papers with lower_year <= source_year <= upper_year (defaults -1 / 2024) are bucketed; target_iteration selects the random-shuffle run directory. Resumable per source year via the finished markers (a finished year is skipped before bucketing, not just before shuffling, so a resumed run does not re-bucket its edges). utils.py is imported from the parent (wos/) directory.
		input: META_DIRE/pid2pub_year{data_suffix}.pkl (from get_meta_data[_with_review].py) + META_DIRE/pid2source_title{data_suffix}.pkl (from venue_validation/get_meta_data_get_venue.py) + META_DIRE/citing_pid2cited_pids_list_valid_source_title{data_suffix}.pkl (from filter_network_valid_source_title.py)
		output (to META_DIRE/random_shuffle_citation_control_venue{data_suffix}/{target_iteration}/): citing_pid2cited_works_list_shuffled_source_{source_year}.pkl + reshuffle_source_{source_year}_finished.pkl (per-source-year markers)

	nobel_disp_mean_quantile.py
		description: Where does the AVERAGE Nobel paper's disruption sit in the whole WoS corpus? One number, in four steps: (1) build the qualifying population from the disruption table ALONE -- every paper in disp_full passing up_refer_count >= reference_threshold, citation_count_y{off} >= citation_threshold and pub_year < max_year; (2) with RESTRICT_TO_NOBEL_VENUES on (the default) narrow that population to the papers published in the SAME VENUES as the Nobel papers themselves, so if the prize papers come out of 10 journals only those 10 journals' papers stay; (3) average the raw disruption index D = disp_y{off} over the Nobel papers among them; (4) report the PERCENTILE RANK of that single average within the disp distribution of the step-2 papers, and draw it -- a Gaussian KDE of all those papers with the area at or below the Nobel mean shaded, and two labelled vertical markers, the Nobel mean and the Nobel median, each annotated in place with its value and its '<x>th pct' rank (no legend, no title). disp_full carries all three filter columns itself (pub_year, up_refer_count, citation_count_y{off} = I + J), so nothing else is read for the population: in particular gen_V3 is NOT read, because its citation_count_y{off} was counted by get_efg.py over ITS year_offset, a different window whenever the two runs disagree -- taking the filter columns from disp_full keeps the filter and the index on one citation window. The ranking is computed from raw disp, so none of compute_efgd_quantile.py's precomputed quantile columns is needed and there is no use_disp_f setting. NOTE the population is disp_full's, not compute_efgd_quantile.py's (which filters gen_V3 and then inner-joins disp_full, so its rows are the INTERSECTION), which is why the counts here can be a little larger than that table's. Note also what step 3 is NOT: it locates ONE summary value on the corpus-wide disp axis, not the mean of the Nobel papers' own percentile ranks -- that is a different statistic and is what award_quantile_analysis.py plots. Both are reported so they cannot be confused. Nobel papers are identified from the publication-record rows flagged 'Is prize-winning paper' == 'YES' by TWO keys in order: DOI (canonicalised by norm_doi, looked up in pid2doi.pkl), then TITLE (norm_title: lower-cased, accents folded, punctuation stripped, whitespace collapsed; pid2title.pkl) for the rows no DOI could place. The title fallback exists because DOI alone barely works here -- the prize-winning papers have a median publication year around 1957 while WoS carries a DOI essentially only from ~1998 on, so a DOI-only join reaches ~30 papers; USE_TITLE_FALLBACK = False restores that behaviour and tags its outputs '_doionly'. Titles shorter than MIN_TITLE_CHARS are never used as a key. Both lookups honour require_unique_match: with it off a key claimed by several pids contributes ALL of them and every output name gains '_multi_match'. How many papers each route contributed is printed and recorded. Non-finite disp values are dropped from BOTH the Nobel mean and the reference distribution, and the venue restriction is applied to that same single population after the thresholds and before any statistic, so the Nobel group, the reference distribution, the KDE curve, the per-cohort figure and the 'other smallest' tail all describe one and the same set. Every paper count (Nobel, other, total) is printed at the end of EVERY run, cached or not. Everything the figure and the CSVs need is cached to a pkl keyed by all the settings; FORCE_RECOMPUTE (or deleting it) rebuilds. use_with_review / k_require_after_focal / year_offset must match the get_disruption.py / arrange_disruption.py run being read. max_year is typed in directly here (not derived from year_offset).
		input: META_DIRE/disruption/disp_full[_y{year_offset}]{data_suffix}{k_suffix}.csv (from arrange_disruption.py; the _y tag only when year_offset != 5 -- supplies BOTH disp_y{off} and the three filter columns), META_DIRE/pid2doi.pkl (from get_meta_data_doi.py), META_DIRE/pid2title.pkl (from get_meta_data.py; the title fallback's index), META_DIRE/pid2source_title{data_suffix}.pkl (from venue_validation/get_meta_data_get_venue.py, same use_with_review; only when RESTRICT_TO_NOBEL_VENUES), NOBEL_DATA_DIRE/<nobel csv> (EXTERNAL Nobel publication records, NOT produced by this pipeline; NOBEL_DATA_DIRE = META_DIRE/nobel_prize, see utils.py)
		output, with {param_suffix} = y{year_offset}{data_suffix}{k_suffix}_rt_{rt}_ct_{ct}_ybefore_{max_year}{venue_tag}{match_tag}{title_tag} (venue_tag = '_nobelvenue' when the population is restricted to the Nobel venues, so a restricted run never overwrites a whole-corpus one). To META_DIRE/nobel_disp_mean_quantile/: nobel_disp_mean_quantile_{param_suffix}.csv (one row per metric: the Nobel mean, its percentile rank, the sample sizes and the corpus-wide reference statistics); nobel_papers_{param_suffix}.csv (one row per IDENTIFIED Nobel paper -- pid, title, pub_year, up_refer_count, citation_count_y{off}, disp_y{off}, the I/J/K counts, matched_by (doi|title) and passed_filter; rows are taken BEFORE the filter so the dropped ones stay visible); nobel_venues_{param_suffix}.csv (only when restricted: one row per venue with its paper count and how many of them are Nobel papers -- the list the restriction is built from); other_smallest{N_SMALLEST_OTHER}_{param_suffix}.csv (the most negative-disruption papers among the OTHERS, to be read beside nobel_papers); nobel_disp_cohorts_{metric}_{param_suffix}.csv (one row per COHORT_WIDTH-year publication cohort: its range, sizes, its own mean/median, and the Nobel mean/median with their percentile AMONG THAT COHORT). 	nobel_disp_mean_quantile_compare_v2.py
		description: The PER-PAPER counterpart of nobel_disp_mean_quantile.py: that script locates ONE number on a corpus-wide axis, this one gives EVERY paper its own quantile inside the tightest comparison set the data supports, then compares the Nobel and non-Nobel distributions of those quantiles. THREE metrics go through identical machinery -- Disruption D = (I-J)/(C+K) (read straight from disp_full's disp_y{off}, since for disruption C = I+J and (I-J)/(C+K) IS (I-J)/(I+J+K)), Foundation F/C (BOTH halves from gen_V3, because f_count and that file's citation_count are counted over the same window by the same run), and Foundation F/(C+K) (the same F count over disp_full's own C + K, i.e. exactly the denominator disp is divided by -- the quantity compute_efgd_quantile.py calls f_over_ijk). THE COMPARISON SET is a (pub_year, venue) cell: the population is the qualifying papers (rt / ct / pub_year < max_year) with their WoS source_title attached; only cells CONTAINING AT LEAST ONE NOBEL PAPER are kept, so every 'other' paper here shares a publication year AND a venue with some Nobel paper; a cell with fewer than MIN_CELL_SIZE papers is dropped whole (the default 1 means NO cut, so no Nobel paper is lost for having had few contemporaries -- at the price that a paper alone in its cell scores 1.0 by definition, which is why the run prints and the CSV records how many Nobel papers are alone in their cell and how many sit in a cell of fewer than 5); inside each surviving cell every paper is ranked per metric with rank(pct=True, method='average'), the same convention compute_efgd_quantile.py uses. Ties share the average rank, which matters because disp has a large atom at exactly 0. A paper missing one metric drops out of that metric's ranking only -- the cells are fixed by the disruption population, so all metrics are read inside identical comparison sets. FIGURES: one figure per metric, disruption in red and both Foundation ratios in blue (told apart by their marker labels and filenames, not by colour), each drawing that metric's Nobel quantile density and marking its own Nobel mean (dashed) and median (dash-dotted) with award-style in-place text labels rather than a legend; all share the [0, 1] quantile axis so they can be read against each other and against 0.5. The other papers are NOT drawn (DRAW_OTHERS puts them back): ranks inside a cell fill the unit interval by construction, so their density is the uniform baseline whatever the data says and the line adds nothing to the number 0.5 -- which IS the comparison. Every statistic of the others is still computed and written out (mean, median, the shares above 0.5 and 0.9, and a Mann-Whitney U test of exactly this shift). Nobel papers are identified exactly as in nobel_disp_mean_quantile.py (DOI then TITLE, both honouring require_unique_match; the fallback is not optional in practice). Everything is cached to one pkl keyed by every setting; FORCE_RECOMPUTE rebuilds. max_year is typed in directly here too.
